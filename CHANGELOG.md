# Changelog

- Criação do projeto NexusCC em TypeScript com arquitetura MVC.
- Painel operacional, usuários/ramais, filas, campanhas, mailing e histórico.
- API autenticada, integração Supabase e serviço Asterisk/WebRTC.

- Documentação técnica, implantação e procedimento de homologação.

Versão de desenvolvimento inicial. Telefonia externa depende de configuração e homologação em infraestrutura real.
